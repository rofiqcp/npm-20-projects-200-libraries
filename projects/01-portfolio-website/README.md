# Project 1: Portfolio Website Statis

**Level:** 🟢 Easy  
**Duration:** 1-2 weeks  
**Complexity:** ⭐

## Tujuan
Memahami HTML/CSS/JavaScript dasar, responsive design, dan static file deployment.

## Tech Stack
- HTML5 / CSS3
- JavaScript (Vanilla)
- Tailwind CSS
- Framer Motion
- Feather Icons

## Database
Tidak ada (static site)

## Features
- ✅ Multi-page portfolio (Home, About, Projects, Contact)
- ✅ Responsive design
- ✅ Smooth animations
- ✅ Dark mode toggle
- ✅ Contact form validation

## Getting Started
```bash
npm install tailwindcss framer-motion feather-icons
```

## Deployment
- GitHub Pages (free)
- atau sirobo.codes + Cloudflare Tunnel

- HTML semantics
- CSS Grid & Flexbox
- Responsive design
- Form validation
- Animation libraries
